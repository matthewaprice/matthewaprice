## What I'm building now

### LinkRail Analytics
A URL shortening and visitor analytics platform, built solo and running in production.

- **Custom PHP 8.5 MVC framework written from scratch** - router, query builder, model layer, typed view/component system, and code generators.
- **A+ 10/10 tests passed on Mozilla HTTP Observatory** - CSP with frame-ancestors enforcement, subresource integrity on all scripts, and Secure/HttpOnly/SameSite cookies.
- **Async analytics pipeline** across four SQS queues (each with a DLQ). Consumers persist raw tracking events and update summary tables in the same pass; dashboards read only from summaries, never raw logs.
- **LLM-powered insights** - natural-language analysis of traffic trends, referrers, and funnel completion, generated by EventBridge-scheduled background jobs behind a tiered cache/DB read-through.
- **Cookie-less tracking** - visitor journeys, page-level analytics, and element click tracking without third-party cookies.
- **AWS production stack** - ECS across three services on arm64, CodeBuild → ECR → CodePipeline, RDS, ElastiCache, S3, SES with SNS deliverability webhooks, ALB.
- **Quality gates** - PHPUnit, Cypress, PHPStan level 5, PHP_CodeSniffer, Husky pre-commit/pre-push.

### Shop Counter - In Development - Demo Available
Team-based SaaS for machine shop operations - machines, parts inventory, maintenance history, and analytics.

- Laravel 13 / PHP 8.5, PostgreSQL, Redis-backed queues

- PHPUnit, PHPStan/Larastan level 5, PHP_CodeSniffer, Psalm, Husky pre-commit/pre-push.
